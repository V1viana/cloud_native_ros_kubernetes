# Validated Results

This directory publishes a compact, reviewable subset of the validated live
results. Complete timestamped logs and generated cluster snapshots remain
local because they are reproducible runtime artifacts.

The `evidence/campaign` directory contains aggregate statistics for E0, E1,
E2, P2 and E4. The `evidence/runs` directory contains one successful live
report per scenario, plus the U1/U2 update checks, observability recovery and
private-registry smoke check.

See [the evidence index](evidence/README.md) for run identifiers, scope and
interpretation. New executions generated by the scenario runners remain
ignored unless deliberately curated into `evidence/`.

# KubeROS Integration Documentation

Questa directory documenta la copia KubeROS usata dal progetto
`cloud_native_ros_kubernetes`.

- [Deployment update API](DEPLOYMENT_UPDATE_API.md)
- [KubeROS upstream documentation](docs_kuberos/deploy_kuberos.md)
- [Advanced setup](docs_kuberos/advanced_setup.md)

I manifest runtime e gli script sperimentali mantenuti dal progetto si trovano
nelle directory radice `manifests/` e `scripts/`. La copia di integrazione
conserva il core KubeROS, la Fleet nativa, lo scheduler e le estensioni per
Deployment e update differenziale.
